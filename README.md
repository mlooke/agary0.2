# متابعة عقود الإيجار

نظام لإدارة ومتابعة عقود الإيجار مع استخراج البيانات من PDF عبر الذكاء الاصطناعي (DeepSeek)، وقاعدة بيانات سحابية مشتركة عبر Firebase Realtime Database.

## المزايا
- مسح عقود PDF واستخراج البيانات تلقائياً بالذكاء الاصطناعي
- متابعة الدفعات ومواعيد استحقاقها وتحديث حالة السداد
- كشف العقود المكررة قبل إضافتها
- قاعدة بيانات سحابية (Firebase) — كل الأجهزة تشترك بالبيانات نفسها
- تحويل أرقام الهواتف تلقائياً (+966 → 05)

## التشغيل محلياً
1. `npm install`
2. ضع ملف `serviceAccountKey.json` (من Firebase → Service accounts) بجانب `server.js`
3. `npm start`
4. افتح http://localhost:3000

## على جهاز ثانٍ
- انسخ `serviceAccountKey.json` من الجهاز الأول (لا يُرفع على GitHub)
- ثم نفس خطوات التشغيل محلياً — وستظهر لك نفس البيانات من السحابة

## النشر السحابي (Railway / Render)
- ادفع الكود إلى GitHub
- أنشئ متغير بيئة `FIREBASE_SERVICE_ACCOUNT` يحوي كامل محتوى `serviceAccountKey.json`
- المنصة تتكفل بالباقي (منفذ `PORT` تُعطيه تلقائياً)

## ملاحظات أمان
- `serviceAccountKey.json` في `.gitignore` — لا ترفعه أبداً على GitHub
- المتغير `FIREBASE_SERVICE_ACCOUNT` سرّي — لا تشاركه

# متابعة عقود الإيجار

نظام لإدارة عقود الإيجار مبني على **Node.js + Express**، ومرتبط بقاعدة بيانات **SQLite حقيقية** تُخزَّن كملف على جهازك (`data/contracts.db`). يعمل بالكامل محليًا داخل VS Code دون الحاجة لأي خدمة خارجية أو اتصال إنترنت بعد التثبيت.

## المتطلبات

- تثبيت **Node.js** (نسخة 18 أو أحدث) من https://nodejs.org — إذا كان مثبتًا تأكد بكتابة `node -v` في الطرفية.

## خطوات التشغيل داخل VS Code

1. فك ضغط هذا المجلد، ثم افتحه في VS Code: `File > Open Folder`
2. افتح الطرفية المدمجة: `Terminal > New Terminal`
3. ثبّت الحزم المطلوبة:
   ```
   npm install
   ```
   (سيقوم هذا بتثبيت Express ومكتبة better-sqlite3 لإنشاء قاعدة البيانات)
4. شغّل الخادم:
   ```
   npm start
   ```
5. افتح المتصفح على: **http://localhost:3000**

عند أول تشغيل يُنشأ تلقائيًا ملف قاعدة البيانات داخل `data/contracts.db`، وكل عقد أو دفعة تضيفها تُحفظ فيه بشكل دائم — حتى لو أغلقت الخادم وشغّلته لاحقًا.

## هيكل المشروع

```
contracts-app/
├── server.js          # خادم Express + منطق قاعدة البيانات (SQLite)
├── package.json        # الحزم المطلوبة
├── data/
│   └── contracts.db    # ملف قاعدة البيانات (يُنشأ تلقائيًا)
└── public/
    └── index.html       # واجهة الموقع (تتصل بالخادم عبر API)
```

## نقاط الـ API المتاحة

| الطلب | الوصف |
|---|---|
| `GET /api/contracts` | جلب كل العقود مع دفعاتها |
| `POST /api/contracts` | إضافة عقد جديد |
| `PUT /api/contracts/:id` | تعديل عقد موجود |
| `PATCH /api/contracts/:id/payments/:index` | تحديث حالة سداد دفعة |
| `DELETE /api/contracts/:id` | حذف عقد |
| `GET /api/settings` | جلب إعدادات التنبيهات |
| `PUT /api/settings` | تحديث إعدادات التنبيهات |

## نوع الدفع ومبلغ كل دفعة

عند إضافة أو تعديل عقد، تختار نوع الدفع:

- **سنوي**: تُولَّد الدفعات تلقائيًا مرة كل سنة بدءًا من تاريخ بداية العقد وحتى تاريخ نهايته.
- **شهري**: تُولَّد الدفعات تلقائيًا مرة كل شهر بدءًا من تاريخ بداية العقد وحتى تاريخ نهايته.
- **مخصص (عدد غير محدود)**: تضيف وتحذف الدفعات يدويًا بأي عدد تريده، وتحدد تاريخ كل دفعة بنفسك.

في كل الحالات، مبلغ كل دفعة يُحسب تلقائيًا = **القيمة الإجمالية للعقد ÷ عدد الدفعات**، ويُعاد حسابه فورًا كلما غيّرت القيمة الإجمالية أو عدد الدفعات أو تواريخ العقد (في وضع سنوي/شهري).

## ملاحظة حول التنبيهات

التنبيهات (دفعات مستحقة، عقود قريبة الانتهاء) تظهر داخل الواجهة عند فتح الصفحة، وليست إشعارات تصلك خارج المتصفح (بريد إلكتروني أو واتساب). إذا احتجت ذلك لاحقًا يمكن إضافته كخطوة تالية.

## نقل المشروع لجهاز آخر

انسخ المجلد بالكامل، بما فيه `data/contracts.db`، وستنتقل بياناتك معه.
